🎨 Design

The website uses a warm bakery-inspired color palette:

Cream

Beige

Chocolate Brown

Golden accents

The design focuses on simplicity, readability, attractive food photography, and a premium bakery experience.

💬 Customer Feedback

Users can enter their name and feedback through the feedback section. After submission, the feedback is dynamically displayed on the same page as a customer review card.

🛒 Shopping Cart

Users can add bakery products to the cart. The cart displays selected products, quantities, and the total price.

📍 Location

The website includes the bakery's location and a Get Directions button that opens Google Maps for navigation.
